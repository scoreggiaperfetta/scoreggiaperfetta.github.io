ScoreggiaPerfetta · ritorno da TikTok

Questa è la pagina di atterraggio del redirect_uri registrato sull'app TikTok. Non fa nulla da sola: serve solo a mostrare il code che TikTok ha appena consegnato, così lo incolli nel comando scoreggia tiktok-auth.

Nessun parametro code nell'indirizzo. Va bene: significa che hai aperto la pagina a mano, oppure che TikTok ha restituito un error.

—
— — —
  1. Torna nel terminale dove hai lanciato tiktok-auth.
  2. Incolla l'URL completo: il comando legge il code e salva il refresh token.
  3. Il code vale una volta sola e scade in pochi minuti: non ricaricare questa pagina e non riusarlo.
